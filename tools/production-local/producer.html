Rehearsal run sheet
  1. With demo sources, put A in Preview, add a title, then TAKE and set local Program live. Unmute A in Program audio and apply. Verify received Program and audio.
  2. Start a camera on A and screen share on B. Include audio only when needed. Confirm the source badges show the selected input and actual sending resolution.
  3. Preview B without changing Program. TAKE using Cut, then Fade. Test split screen, picture in picture, title and logo.
  4. Test Program gain and mute. With headphones, enable local listening and verify that monitor mute is separate from Program mute.
  5. Choose an existing moving MP4/WebM on either input. Test pause/resume, rewind and loop. Files remain ephemeral in this browser.
  6. Save a scene, change Preview, then reload the scene and TAKE. In a second tab, verify stale commands report a conflict.
  7. Stop sharing using the browser’s own control. Confirm source-unavailable fallback, then reconnect the input.
  8. With Program moving, use a ready primary, then test primary stall and crash below. Confirm standby takeover and restored readiness; these local fault tests interrupt Program.
  9. Finish with Stop rehearsal & captures. Confirm browser capture indicators disappear. No media recording is created.

Real camera/display permissions, device compatibility, file codecs and perceived lip sync need your attended rehearsal. Automated checks use generated or fake devices and do not establish physical-device success.
